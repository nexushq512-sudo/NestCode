
# ⚫ OnyxCode

Hey! 👋

I'm **Sandip Roy**, a **14-year-old developer** from India, and this is **OnyX Code**.

I started building OnyX Code because I wanted a coding experience that felt faster, smarter, and more collaborative. Instead of switching between different tools, I wanted everything in one place—real-time collaboration, AI assistance, and a clean developer experience.

This project is still evolving, and I'm constantly learning and improving it with every commit.

## Why OnyX Code?

* 🤝 Real-time collaborative coding
* 🤖 AI-powered coding assistance
* ⚡ Fast and modern web editor
* 🌍 Built for students, developers, and teams
* 🚀 More features are coming soon...

## My Goal

I'm not trying to build just another code editor.

I'm trying to build a place where coding feels effortless, collaboration feels natural, and anyone can turn an idea into reality.
